Flagship · operations platform

Mobigo: contracts, signatures and WhatsApp in one place

Self-hosted DocuSeal with a WhatsApp session manager bolted on top. Rental agreements go out for signature, come back signed, and the same system sends the reminders, collects the consent forms, and keeps IMEI records straight.

Built for my own rental business, so the requirements were never theoretical. It handles CTOS and CBM consent forms, multi-session WhatsApp routing, and a forwarding layer that sends each customer reply to the right staff member.

TypeScriptNodeDocker PostgresRedisDocuSeal

Product · Chrome extension

DualSub: learn a language while you watch

A Manifest V3 extension for YouTube and streaming sites that shows two subtitle tracks at once, then highlights only the words worth learning at your level. The AI mode translates each line and picks the words to teach in the same call.

Live on the Chrome Web Store with a seven-language site, an authenticated study portal, and an eval harness that grades model output against 530 real subtitle lines before any prompt change ships.
